# Phase 2: Light UI + V4 layout

- White background, dark text, subtle gray borders and cards.
- Options Analytics has the five V4 modes and matching chart slots.
- Day vs Night has separate day and night label dates and the finalized four chart titles.
- Load and Run buttons are intentionally non-computing until the V4 backend is integrated.

## Update an existing project
Copy `app/globals.css`, `app/analytics/options/page.tsx`, and `components/SmileChart.tsx` from this archive into your existing project, overwriting those three files.

Run `npm run dev` and refresh http://localhost:3000.
